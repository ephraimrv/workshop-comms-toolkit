First three questions, in order

1. getwd()Does it end in the dataset folder? If not: Session → Set Working Directory → To Source File Location
2. list.files("data")Are the CSVs actually there? Confirms path AND that files were extracted.
3. Did they run the chunks above?Most "not found" errors are skipped chunks, not typos.

Documented in the materials (§17)

object 'kinetics' not foundImport chunk not run (or it failed). Re-run the chunk that creates kinetics.
cannot open file / does not existgetwd() → list.files() → list.files("data")
could not find function "%>%"library(dplyr)
could not find function "ggplot"library(ggplot2)
object 'time_hr' not foundCase-sensitivity. Time_hr ≠ time_hr ≠ TIME_HR. Check names(kinetics).
graph renders emptyFilter matched nothing. table(kinetics$Metric), dim(od_data)

Not in the materials — expect these anyway

Console shows + and seems frozenPress Esc. Unclosed ( or ". Most common beginner lockup — they will think R has crashed.
there is no package called 'x'Not installed (≠ not loaded). install.packages("x") then library(x)
package 'phyloseq' is not availableBioconductor, not CRAN. BiocManager::install("phyloseq")
unexpected input / unexpected symbolCurly quotes from copy-paste. Retype " manually, or check for “ ”.
Red stop sign in console cornerR is busy, not broken. Wait, or click it to interrupt.
Works on my Mac, fails on their WindowsFilename case. macOS is case-insensitive by default; check exact spelling against list.files().
Nothing happens on RunCursor in the Console, not the Script pane — or no line selected. Ctrl/Cmd+Enter runs the current line.
Plot pane blank / "figure margins too large"Plot pane too small. Drag it larger, or zoom out.

Escalation

Do not debug one person for more than ~90 seconds during a live exercise. With 29 participants in a two-hour block, one long stop costs the room. If it is not on this card: seat them beside a working neighbour, note the name and the error, and return at the break. A participant who watches someone else's screen for five minutes learns more than one who watches you type.

If several people hit the same thing at once, stop the room and fix it out loud once. Ask Dr. Forteza to pause rather than solving it 29 times in parallel.
